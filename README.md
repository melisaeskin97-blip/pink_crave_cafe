# 🍰 Pink Crave - Tatlı Kafe Web Sitesi

## 📖 Proje Hakkında

Pink Crave, HTML, CSS ve JavaScript kullanılarak geliştirilmiş modern ve kullanıcı dostu bir tatlı kafe web sitesi projesidir. Kullanıcılar tatlıları görüntüleyebilir, favorilerine ekleyebilir, puanlayabilir ve kategoriye göre filtreleyebilir.

## ✨ Özellikler

* 🍰 Şık ve modern kafe tasarımı
* 🔍 Tatlı arama sistemi
* 📂 Kategori filtreleme
* ❤️ Favorilere ekleme ve kaldırma
* ⭐ 5 yıldızlı puanlama sistemi
* 🔥 Kalori bilgileri görüntüleme
* 💾 LocalStorage ile verileri kaydetme
* 📱 Responsive (mobil uyumlu) tasarım
* 🎨 Pembe temalı kullanıcı arayüzü

## 🛠️ Kullanılan Teknolojiler

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* LocalStorage API

## 📸 Ekran Görüntüsü

Projenin ekran görüntüsünü buraya ekleyebilirsiniz.

## 🚀 Kurulum

1. Repoyu klonlayın:

```bash
git clone https://github.com/kullaniciadi/pink-crave.git
```

2. Proje klasörüne girin:

```bash
cd pink-crave
```

3. `index.html` dosyasını tarayıcıda açın.
